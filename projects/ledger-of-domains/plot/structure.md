# Estructura general de la obra (Libro → Arco → Capítulos)

**Propósito de este nodo:** mapa rápido de a qué arco y libro pertenece cada capítulo, en la numeración fusionada real (la de los archivos `Capitulo N.md`). Consultar esto ANTES de tocar cualquier reestructuración de arcos/capítulos — evita tener que re-explicar las divisiones internas cada sesión. Para resúmenes capítulo a capítulo, ver `chapters/index.md`. Para el plan beat-a-beat de Libro2, ver `chapter-plan-libro2.md`.

**Regla de mantenimiento:** actualizar este archivo cada vez que se escriba un capítulo nuevo, se retitule uno existente, o se muevan límites de arco — es la primera fuente a corregir, antes que `chapters/index.md` (que lleva el detalle) o cualquier ficha de personaje.
