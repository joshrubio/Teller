# System — La Cuerda Bajo el Agua

No hay Domain en esta historia. Ni Zeke ni Sanne son usuarios activos de Odem — son dos firmas pasivas que se entrelazaron por proximidad sostenida, no por diseño ni entrenamiento.

Ver `world/vinculo.md` para el mecanismo completo. Este archivo existe solo para dejar explícito, para cualquier sesión futura, que este proyecto no usa Domains, Potestades, ni Rango — se apoya en una sola dimensión de `projects/ledger-of-domains/world/odem.md`: "Bond between the living."
